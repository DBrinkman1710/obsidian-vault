## Architecture notes (post-session)

### Container layout (all app environments)

```
nginx (ports 8000 + 8080)
  ├── / → serves /usr/share/nginx/html (React SPA)
  ├── /api/* → proxy_pass http://localhost:8001
  └── /ws/* → proxy_pass http://localhost:8001 (WebSocket upgrade)

uvicorn (port 8001, internal only)
  └── FastAPI app
```

### Why two nginx ports?

Railway caches the service port per environment at first deployment. Production learned port 8080; sandbox learned port 8000 (from when only uvicorn existed). Rather than resetting Railway's cache (requires dashboard access), nginx just listens on both.
